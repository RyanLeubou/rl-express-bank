# Identité visuelle RL EXPRESS BANK

Emblème : **trident doré poli** : flèche centrale barbelée, dents latérales en S à pointes crochues, double collier, manche court ; épaisseur en perspective cavalière (fuyante à 45°, or sombre). Dessin vectoriel original.

| Fichier | Usage |
| --- | --- |
| `trident.svg` | Trident seul, fond transparent (rapport, slides) |
| `favicon.svg` | Icône d'application sur fond Encre Wouri |
| `rl-express-bank-trident-1024.png` | Trident seul en PNG haute définition |
| `rl-express-bank-app-icon-512.png` | Icône d'application en PNG |
